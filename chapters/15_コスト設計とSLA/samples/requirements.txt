# 第15章サンプルの依存
#
# 本章のサンプルは、コストとSLAの「試算の構造」をオフラインで確かめるためのもので、
# APIキー・ネットワーク・外部ライブラリを一切必要としない（標準ライブラリのみ）。
# したがって、この requirements.txt に必須の外部依存はない。
#
# 本番では、ここで使う「擬似の単価表・擬似のレート上限・擬似のトークン数」を、
# 実際の料金表・契約ティアの実値・API レスポンスの usage に置き換える。
# 実料金・実 API に置き換えるときは、使うモデル提供者の公式 SDK を各自で追加すること
# （例：anthropic / openai / google-genai）。単価・上限は変動が速いので使う時点の公式で確認する。
