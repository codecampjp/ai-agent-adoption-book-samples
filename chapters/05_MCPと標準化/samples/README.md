# 第5章 MCPと標準化 — サンプル

本書 第5章のハンズオン素材です。この章にPythonのサンプルコードはありません（MCPサーバーを自分で書くのは第8章です）。代わりに、5-3節「既存のMCPサーバーを使ってみる」のハンズオン手順書を収録しています。

公開済みのMCPサーバー（ファイルシステムサーバー）にMCP Inspectorでつなぎ、`tools/list`（道具の一覧）と `tools/call`（実行）を自分の目で確かめられます。
