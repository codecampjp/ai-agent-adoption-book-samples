# 第13章 サンプルコード（評価と観測性 ── 動く→動き続ける）

本書 第13章の掲載コードを、そのまま実行できる形にまとめたもの。
ファイル名の先頭は対応する節番号（例 `13-2_` = 13-2節）。

本文では「評価と観測が回り続けるループ」（図13-2-1）の構造に集中するため、周辺コードを省いて
骨格だけを掲載している。ここではその周辺コードを補い、**APIキー・ネットワーク・外部SaaS不要の
ドライラン**で、次の流れをオフラインで完走できるようにしている（本文 13-2〜13-7）。

1. 小さな**評価データセット**（入力＋期待する観点）を用意する（`13-3_dataset.py`）
2. 擬似エージェントの出力／トラジェクトリを**擬似ジャッジ**で採点する（`13-2_trajectory_and_judge.py`）
3. **合格ライン（しきい値）を割ったら失敗として返す**回帰テスト風の判定（`13-7_regression.py`）
4. 実行**トレース（擬似スパン）**を1件ダンプして観測性の形を見せる（`13-5_trace_dump.py`）

擬似化の考え方は第10〜12章と同じ。**本番では、擬似エージェントを実際のエージェント（第10〜12章）に、
擬似ジャッジを promptfoo の `llm-rubric` や deepeval の `GEval`（LLM-as-a-Judge）に、擬似スパンの
ダンプを LangSmith / Langfuse のトレースに置き換える**。

| ファイル | 対応節 | 内容 | 追加依存 |
|---------|-------|------|---------|
| `_common.py` | 13-3/13-2 | 評価データセット＋擬似エージェント＋擬似ジャッジ | なし |
| `13-3_dataset.py` | 13-3 | 評価データセット（入力＋期待する観点）を表示 | なし |
| `13-2_trajectory_and_judge.py` | 13-2 | Trajectory Eval＋LLM-as-a-Judge（擬似ジャッジ）でスコアを出す | なし |
| `13-5_trace_dump.py` | 13-5 | 実行トレース（擬似スパン）を1件ダンプ（観測性の形） | なし |
| `13-7_regression.py` | 13-7 | 合格ラインを割ったら失敗（exit 1）＝回帰テスト風の判定 | なし |
| `13-4_promptfoo/promptfooconfig.yaml` | 13-4 | promptfoo の設定例（公式準拠・**要 Node.js＋APIキー**） | promptfoo (npm) |
| `13-4_deepeval_geval.py` | 13-4 | deepeval GEval の実例（公式準拠・**要 APIキー**） | deepeval |

`13-4_*` の2つは、本文で紹介する評価ツールを実際に動かす場合の**設定・実例**で、採点用の
LLM（APIキー）や Node.js が要る。オフラインのドライラン（1〜4）とは別枠。

## 動作確認バージョン

- Python 3.10 以上（実行確認は 3.12）。オフラインのドライランは**標準ライブラリのみ**で動く。
- 評価・観測ツール（promptfoo／deepeval／LangSmith／Langfuse）は更新が速い。`requirements.txt`
  では任意依存に版の上限を付けてコメントアウトしている。使う時点で公式ドキュメントを確認すること。

## 実行

### セットアップ（オフラインのドライランは依存インストール不要）

```bash
cd samples
python3.12 -m venv .venv          # 3.10+ ならOK
source .venv/bin/activate          # Windows は .venv\Scripts\activate
# オフラインのドライラン（下記4本）は追加インストール不要（標準ライブラリのみ）
```

### ドライラン（APIキー・ネットワーク・外部SaaS不要）

```bash
python 13-3_dataset.py                 # ① 評価データセットを見る
python 13-2_trajectory_and_judge.py    # ② 採点（Trajectory Eval＋LLM-as-a-Judge代役）
python 13-5_trace_dump.py              # ④ 擬似トレース（スパン）を1件ダンプ
python 13-7_regression.py              # ③ 回帰テスト（合格ラインで合否・割ると exit 1）
```

## 期待される出力（抜粋）

### `13-7_regression.py`

```text
=== 回帰テスト（評価データセット全件）===
  [D1] score=1.00 PASS
  [D2] score=1.00 PASS
  [D3] score=1.00 PASS

全体スコア: 1.00（合格ライン: 0.9）
青信号：合格ラインを満たしています。
```

3件（正常系＋弾くべきケース2件）が期待の観点と道筋を満たし、合格ラインを超えて「青信号」に
なる。擬似エージェントの振る舞いを崩すと（例：権限チェックを外す）、スコアが下がり合格ラインを
割って `exit 1`（赤信号）になる ── CIがビルドを止めるのと同じ骨組み。
