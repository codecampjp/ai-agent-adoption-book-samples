# 第14章 サンプルコード（ガードレールとガバナンス ── 多層防御）

本書 第14章の内容を、そのまま実行できる形にまとめたもの。
ファイル名の先頭は対応する節番号（例 `14-3_` = 14-3節）。

本文では「多層防御の関所」（図14-2-1）の構造に集中するため、掲載コードは骨格に絞っている
（本文の掲載コードブロックは0。擬似ガードの実体はここに置いた）。ここでは **APIキー・
ネットワーク・外部ライブラリ不要のドライラン**で、次の多層防御の一周をオフラインで完走できる。

1. 危険入力（インジェクション文・PIIを含む依頼）を**入力ガード**が検知してブロック／サニタイズ（`14-3_io_filter.py`）
2. **権限最小化スコープ**で許可外ツール呼び出しを弾く（`14-4_tool_scope.py`）
3. 出力に混じった機密／PIIを**出力ガード**がマスキング（`14-3_io_filter.py` / `14-5_pii_masking.py`）
4. しきい値超過ケースを**HITLへエスカレーション**（`14-7_hitl_escalation.py`）
5. 一連の判断を**監査ログ1件にダンプ**（`14-6_audit_log.py`）

擬似化の考え方は第10〜13章と同じ。**本番では、擬似入力／出力ガードを Guardrails AI や
各クラウドのガードレール（Amazon Bedrock Guardrails / Azure AI Content Safety）に、
PII検出・マスキングを Microsoft Presidio に、権限スコープを実際のツール認可（第4・8章）に、
HITL を LangGraph の interrupt（第11章）に置き換える**。

| ファイル | 対応節 | 内容 | 追加依存 |
|---------|-------|------|---------|
| `_common.py` | 14-2〜14-7 | 擬似ガード（入力／出力／権限スコープ／HITL／監査ログ）＋題材リクエスト | なし |
| `14-3_io_filter.py` | 14-3 | 入力ガード（ブロック／サニタイズ）＋出力ガード（マスキング） | なし |

| `14-7_hitl_escalation.py` | 14-7 | しきい値超過／不可逆操作を HITL へエスカレーション | なし |

## 動作確認バージョン

- Python 3.10 以上（実行確認は 3.12）。オフラインのドライランは**標準ライブラリのみ**で動く。
- ガードレール／PIIツール（Guardrails AI／Presidio／各クラウド）は更新が速い。`requirements.txt`
  では任意依存に版の上限を付けてコメントアウトしている。使う時点で公式ドキュメントを確認すること。

## 実行

### セットアップ（オフラインのドライランは依存インストール不要）

```bash
cd samples
python3.12 -m venv .venv          # 3.10+ ならOK
source .venv/bin/activate          # Windows は .venv\Scripts\activate
# オフラインのドライラン（下記）は追加インストール不要（標準ライブラリのみ）
```

### ドライラン（APIキー・ネットワーク・外部ライブラリ不要）

```bash
python 14-3_io_filter.py         # ① 入力ガード（ブロック/サニタイズ）＋③ 出力ガード
python 14-4_tool_scope.py        # ② 権限最小化スコープで許可外ツールを弾く
python 14-5_pii_masking.py       #    PII 検出とマスキング（正規表現の限界も見る）
python 14-7_hitl_escalation.py   # ④ しきい値超過を HITL へエスカレーション
python 14-6_audit_log.py         # ⑤ 一連の判断を監査ログ1件にダンプ
```

## 期待される出力（抜粋）

### `14-7_hitl_escalation.py`

```text
=== HITL エスカレーション判定（しきい値=2）===
  [R1-normal] risk=0 → 自動で応答
  [R2-injection] risk=2 → HITL（人間の承認）へ
        理由: インジェクション疑い
  [R3-irreversible-pii] risk=3 → HITL（人間の承認）へ
        理由: 許可外ツール, 不可逆操作
  [R4-output-leak] risk=1 → 自動で応答
        理由: 出力に機密/PII
```

正常系（R1）は素通り、インジェクション（R2）と許可外の不可逆操作（R3）はHITLへ、出力に機密が
混じったケース（R4）は出力ガードでマスキングしたうえで応答する。擬似ガードのしきい値や
ルールを変えると、どのケースが人へ上がるかが変わる ── 多層防御の勘どころを手元で試せる。
